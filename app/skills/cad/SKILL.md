# CAD 生成、检查与验证

## 目的

从自然语言需求创建或修改参数化 CAD 模型，生成经过验证的 STEP/STP 工件，检查几何引用，并返回经过检验的输出结果。将 STEP 作为主要的 CAD 工件。将 STL、3MF 和原生 GLB 作为从 STEP 优先流程分支的次要导出工作流。对于装配体，当零件具有功能装配关系时，优先使用 cadpy.assembly.AssemblyHelper，配合源级 build123d 关节、命名配合基准和原生标签。

进入 STEP 工作流有两种方式：从 build123d Python 源生成（从头设计或修改生成模型时的默认方式），或直接导入现有的 STEP/STP 文件（当不存在生成器或用户明确以 STEP 文件为目标时）。两者都生成相同的可检查工件。

## 使用场景

适用场景包括用户请求 CAD 文件、STEP/STP 文件、build123d 源代码、选择器引用（如 #o1.2.f1）、机械零件、装配体、外壳、支架、夹具、孔、沉头孔、沉孔、槽、型腔、凸台、支座、加强筋、圆角、倒角、壳体、源级关节、配合或测量。也适用于用户提供参考图片或要复制的零件的 2D 技术图纸，或从中提取设计意图。

也适用于用户请求从 CAD 几何生成 STL、3MF 或原生 GLB 输出的场景。将这些工作流保持为次要，并加载 supported-exports.md 了解详情。对于 2D DXF 图纸，使用 DXF 技能；当 DXF 从 3D 零件投影时，此技能拥有 STEP 几何，DXF 技能拥有图纸。

此技能不适用的场景包括仅渲染的概念艺术、CAM 刀具路径、工程认证、FEA 结论、建筑 BIM 或手绘插图，除非用户同时需要 CAD 几何。

## 默认约定

除非用户另有指定，否则使用以下默认值。这些是初版建模默认值，而非可制造性、公差或认证声明：

- 单位：毫米。
- 原点：按照 references/positioning.md 中的零件类型默认值；若无更合适的选择，则设为主零件或装配体的中心。
- 基准平面：XY。
- 拉伸方向轴：正 Z。
- 输出几何：闭合的正实体，除非用户请求曲面或构造几何。
- STEP 结构：一个有效实体、实体组合或带标签的装配体组合。
- 装配体结构：固定根部零件、零件局部坐标系、命名配合基准、由 build123d 关节支持的 AssemblyHelper 关系（适用时）、显式生成的放置和详细的原生标签。
- 小型塑料外壳壁厚：未指定时为 2.0-3.0 毫米。
- 装饰性圆角：对局部几何安全时为 1.0-3.0 毫米。
- M3/M4/M5 标准间隙孔：3.4/4.5/5.5 毫米，除非要求其他标准。
- 仅当缺少信息导致模型无法创建、涉及配合关键、安全关键或合规性时，才提出一个有针对性的澄清问题。否则，在明确假设的前提下继续操作。

## 工具与路径

从此技能目录，启动器格式为:

python scripts/step ...      # STEP 生成、GLB/拓扑工件、网格侧文件
python scripts/inspect ...   # 引用、测量、对齐、帧、差异
python scripts/snapshot ...  # PNG/GIF 可视化审查包

使用当前项目的 Python 解释器；将示例中的 python 视为解释器占位符。使用 python scripts/<tool> --help 获取完整的当前命令接口。

目标路径从命令的当前工作目录解析，而非技能目录。从拥有工件的工作区目录运行命令，并传递相对于 cwd 的目标路径。除非用户明确要求，否则将 STEP 输出及其 Python 生成器放在同一目录中，保持相同的基本名称。

CAD 引用是目标本地的 #... 选择器标记，例如 #o1.2 或 #o1.2.f1。使用 CAD CLI 时，将 STEP/CAD 文件作为单独的目标参数传递。

## 必需工作流

根据任务规模调整工作深度：简单零件需要简短描述和少量规格驱动的检查；装配和配合关键的工作需要完整的定位和对齐验证。

1. 分类任务 - 新零件、新装配、源修改、直接 STEP/STP 检查、参考选择、测量/对齐检查、快照审查或次要导出请求。
2. 仅加载所需参考 - 使用下面的触发条件而非读取整个参考集。
3. 编写自然语言 CAD 简述 - 从所有提供的输入中提取尺寸、单位、坐标约定、特征意图、输出路径、假设和验证目标。参见 references/cad-brief.md。
4. 检查可购命名组件 - 当装配中包含命名组件时，在创建简化占位几何之前，先搜索 step-parts 技能。
5. 编码前规划 - 在编辑之前定义参数、意图标签、源路径、预期边界框以及任何配合/定位基准。
6. 编辑源文件而非生成工件 - 使用 gen_step() 编写 build123d Python 代码。
7. 生成明确目标 - 仅对明确目标运行 scripts/step。
8. 几何验证 - 运行 scripts/inspect 作为基线，然后用针对性的检查来验证规格要求的尺寸和关系。
9. 为主 STEP 生成快照 - 快照验证是强制性的。
10. 修复并重新运行 - 如果检查失败，更改最小的负责源部分，重新生成并重新运行验证。

## 交接

完成创建或修改 .step、.stp、.stl、.3mf 或原生 .glb 工件的 CAD 工作后，当 CAD Viewer 已安装时，必须始终将明确的文件路径传递给它。CAD Viewer 必须在未运行时启动之，并返回所创建或更新文件的链接。如果不可用或启动失败，报告该情况并依赖 CLI 检查。

## 不可妥协项

将 STEP 作为主要的经过验证的 CAD 工件。生成的 STEP/STP、STL、3MF、GLB 和渲染文件是派生工件。

使用命名参数、闭合实体、详细的 build123d 标签和版本控制的几何意图。

在源代码中编写装配体定位。references/positioning.md 具有权威性。

不要使用 git status 或文件大小变化作为 CAD 比较。比较源更改或 inspect 摘要。
