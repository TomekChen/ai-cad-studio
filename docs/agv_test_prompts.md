# AGV 底盘测试提示词

以下提示词可直接复制到 AI CAD Studio 的输入框中使用，覆盖不同场景和复杂度。

---

## 基础测试（验证基本功能）

### 提示词 1：标准 AGV 底盘
```
做一个1.2米长、0.8米宽的AGV底盘，四轮驱动，能承载100公斤
```

**预期效果**：生成标准尺寸底盘，板厚8mm，纵梁120mm高，4个轮子对称分布。

---

### 提示词 2：中型承载
```
做一个1.5米长、0.6米宽的AGV底盘，四轮驱动，能承载200公斤，要有电池仓
```

**预期效果**：板厚自动加厚到10mm（中载），纵梁144mm，轴距1125mm，轮距480mm，带电池仓。

---

### 提示词 3：重型承载
```
做一个2米长、1米宽的重型AGV底盘，承载800公斤，用于工厂自动化搬运
```

**预期效果**：板厚加厚到约11mm（重载），纵梁168mm，轴距1500mm，轮距800mm，结构更粗壮。

---

## 进阶测试（验证参数灵活性）

### 提示词 4：紧凑型仓储 AGV
```
做一个紧凑型AGV底盘，长0.8米宽0.4米，用于窄通道仓储，承载150公斤，轮子要小一点
```

**预期效果**：小尺寸底盘，轮子半径约80mm，适合窄通道环境。

---

### 提示词 5：多横梁加强型
```
做一个1.8米长、0.9米宽的AGV底盘，承载500公斤，横梁数量要多一些，至少5根
```

**预期效果**：cross_count=5，横梁间距更密，结构刚性更强。

---

### 提示词 6：长轴距高速型
```
做一个AGV底盘，长1.6米宽0.7米，轴距要长一些，轮距也要宽，承载300公斤
```

**预期效果**：轴距约1200mm（>75%长度），轮距约560mm（>80%宽度），稳定性更好。

---

## 极限测试（验证边界情况）

### 提示词 7：超小型
```
做一个0.6米长、0.3米宽的迷你AGV底盘，承载50公斤
```

**预期效果**：最小尺寸测试，验证小尺寸下的几何合理性。

---

### 提示词 8：超大型
```
做一个3米长、1.5米宽的超大型AGV底盘，承载2吨，用于港口集装箱搬运
```

**预期效果**：超大尺寸，板厚约12mm，纵梁200mm+，验证大尺寸下的结构完整性。

---

## 演示推荐流程

**给客户演示时，建议按以下顺序**：

1. **先演示提示词 2**（中型承载）— 最典型的场景，效果最好
2. **再演示提示词 3**（重型）— 展示承载能力自动换算
3. **最后演示提示词 4**（紧凑型）— 展示参数灵活性

每个演示步骤：
1. 输入提示词 → 点击"生成三维模型"
2. 等待 3D 预览出现（约 10-30 秒）
3. 点击"下载 STEP (SolidWorks)"
4. 用 SolidWorks 打开，展示实体模型
5. 在 SolidWorks 里做简单的干涉检测或质量属性查看

---

- [ ] STEP 文件能在 SolidWorks 中正常打开

- [ ] 电池仓、电机座、安装孔位置合理
- [ ] 模型可以做有限元分析（网格质量）
